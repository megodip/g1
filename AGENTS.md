# AGENTS.md — памятка для ИИ-разработчиков

Этот файл — главный документ для любой ИИ-модели (или человека), дорабатывающей
проект **Vegas**. Прочитай целиком перед изменениями; это займёт меньше минуты
и убережёт от поломки совместимости с кнопочными телефонами.

## 1. Что это и жёсткие ограничения

Мини-портал для **кнопочных телефонов**, браузеры которых часто:

- **не поддерживают JavaScript** — НИКОГДА не добавляй `<script>`, inline-обработчики
  (`onclick=...`), `javascript:`-ссылки и fetch/XHR/WebSocket;
- имеют узкий экран и медленный интернет — страница целиком должна быть
  **меньше ~15 КБ**, лучше 2–5 КБ;
- поддерживают только базовый HTML4/XHTML-MP: обычные формы (`method`/`action`),
  ссылки, таблицы, `<iframe>`, `<meta http-equiv="refresh">`. Без flexbox, grid,
  float, `position:fixed`, HTML5-секционных тегов.

Динамичность достигается двумя без-JS инструментами:

| Инструмент | Что делает | Где применять |
|---|---|---|
| `<meta http-equiv="refresh" content="N">` | автообновление страницы | **только** внутри iframe (иначе ломается ввод текста) |
| `target="имя_фрейма"` у формы/ссылки | отправляет результат в iframe, не трогая текущую страницу | чат, любые «живые» области |

Образец механики — `app/modules/chat.py` (принцип wapchat). Не ломай её.

## 2. Стек и запуск

- Python **3.7+**, только стандартная библиотека. Никаких `pip install`.
- Запуск: `python3 server.py` (порт/хост/ключи — `app/config.py` или env `VEGAS_*`).
- Данные — обычные файлы в `data/` (создаётся сам). В git не коммитится.

## 3. Карта проекта и правила слоёв

```
server.py        -> только запуск
app/config.py    -> ВСЕ настройки; каждый модуль берёт значения отсюда
app/core/        -> HTTP-ядро. НЕ ЗНАЕТ про вкладки (кроме 404/500 страниц)
  http.py           Request: .q("имя"), .cookie("имя"), .form
                    Response: .html | .redirect | .binary | .file; make_cookie/del_cookie
  router.py         Route("GET"| "POST", "/путь", функция); Router
  server.py         диспетчер: Request -> handler(req) -> Response; ловит исключения -> страница 500
app/ui/
  layout.py         layout.page(заголовок, активная_вкладка, тело, ...) -> Response
                    с чёрной шапкой (.hdr) и навигацией; layout.raw_page(...) — без шапки (для iframe)
  components.py     готовые блоки: msg_box, error_box, chat_row, pager, nl2br
app/services/     -> логика без HTML: fetcher (внешние HTTP), storage (файлы/чат),
                    library (локальная библиотека), llm (Вега)
app/modules/      -> вкладки. КАЖДАЯ вкладка = один файл с ROUTES
```

Правила зависимостей (не нарушать, чтобы не получить циклы импортов):

- `modules/*` → могут импортировать `core`, `ui`, `services`, `config`;
- `services/*` → только `config` (+ стандартная библиотека);
- `ui/*` → только `config` (и `core.http` внутри функций);
- `core/*` → `config`, `ui.layout` (для страниц ошибок).

## 4. Контракт обработчика

```python
def pg_...(req):                # req: app.core.http.Request
    ...
    return layout.page("Заголовок", "ключ_вкладки", html_тело)   # обычная страница
    return Response.redirect("/путь")                            # редирект
    return Response.file(path, name)                             # файл на скачивание

ROUTES = [Route("GET", "/путь", pg_...), Route("POST", "/путь", po_...)]
```

- Обработчик **возвращает** `Response` (ничего не печатает в stdout).
- Все настройки — из `app.config`, никаких литералов вроде портов/лимитов в модулях.
- Русские тексты в UI; комментарии объясняют «почему», а не «что».

## 5. Рецепт: добавить новую вкладку (3 шага)

1. Создай `app/modules/<ключ>.py` по образцу `archive.py` (самый простой):

```python
# -*- coding: utf-8 -*-
"""Вкладка «<Название>»: что делает (2-3 строки)."""

from app.core.http import Response
from app.core.router import Route
from app.ui import layout

def pg_example(req):
    body = "<h1>Название</h1><p>Контент...</p>"
    return layout.page("Название", "example", body)

ROUTES = [Route("GET", "/example", pg_example)]
```

2. В `app/modules/__init__.py`: импортируй модуль и добавь в `MODULES`.
3. В `app/config.py` добавь `("<ключ>", "Название")` в `TABS` — вкладка сама
   появится в чёрной шапке на всех страницах.

## 6. Рецепт: добавить настройку

В `app/config.py`: `ИМЯ = os.environ.get("VEGAS_ИМЯ", "дефолт")`. Используй её в
модуле через `config.ИМЯ`. Никаких настроек в других файлах.

## 7. Правила предметной области (книги)

- Книги хранятся ТОЛЬКО чистым текстом (`data/library/<id>.txt`, карточки в
  `data/library.json` — см. `services/library.py`).
- Никаких ссылок на форматы (epub/pdf/fb2-файл) пользователю: кнопочный
  телефон их не читает. Кнопка «в библиотеку» у Флибусты — единственный путь.
- Чистый текст добывается из **структуры fb2** (XML: title-info + body/p) или
  из plain txt. НИКОГДА не отдавай пользователю результат прокси-выкачки
  HTML-страницы книги как «книгу» — там сайт-мусор (меню, алфавит, ссылки).
- Чтение — постранично (`library.paginate`), страница ~6 тыс. знаков.

## 8. Правила UI (краткий чек-лист)

- Новые страницы — через `layout.page(...)`; содержимое iframe — через `layout.raw_page(...)`.
- Стили — только общий блок `CSS` в `layout.py` (компактный, без новых технологий);
  шапка — чёрная с белым текстом (`.hdr`), не меняй это без запроса пользователя.
- В чате НОВЫЕ сообщения отображаются СВЕРХУ (`render_messages` переворачивает
  хронологию). Не меняй порядок.
- Повторяющиеся куски HTML — функции в `components.py`, а не копипаста.
- Кнопки — `<input type="submit">`; поля с `maxlength`; после формы — пояснение
  `.small`, что произойдёт.
- Пользовательский ввод в HTML — только через `escape()` / `components.nl2br()`.
- URL с параметрами: `&amp;` внутри HTML-атрибутов (пагинация в `pager` уже так умеет).
- Кириллица в query может прийти сырыми байтами UTF-8 — `Request` уже чинит
  кодировку (`_fix_latin1`), не дублируй это в модулях.

## 9. Тестирование

```bash
python3 server.py &                     # сервер на :8000
bash scripts/test_vegas.sh              # все маршруты, чат, библиотека, отсутствие JS
```

Чек-лист перед коммитом:

- [ ] `grep -ri "<script" app/` — пусто; `onclick|onload|onsubmit` — пусто
- [ ] страницы вкладок < 15 КБ (тест проверяет автоматически)
- [ ] все маршруты отвечают (тест проходит без FAIL)
- [ ] чат: главная страница без `meta refresh`, у `/chat/frame` — с ним
- [ ] чат: последнее сообщение первое на странице (новые сверху)
- [ ] `python3 -m py_compile app/**/*.py server.py` — без ошибок

## 10. Чего делать нельзя

- Ломать iframe-механику чата (см. §1) или ставить `meta refresh` на страницы с вводом.
- Добавлять зависимости (pip, бинарники, БД) — замена хранилища допустима только
  внутри `services/storage.py` и `services/library.py`.
- Хардкодить настройки в модулях.
- Использовать HTML5-теги (`header/nav/section`), CSS3-раскладку, JS.
- Показывать пользователю ссылки на файловые форматы книг (epub/pdf/...) или
  выдавать прокси-выкачку HTML за «текст книги» (см. §7).
- Коммитить `data/` и ключи LLM в код (только env `VEGAS_LLM_KEY`).
